# Project: Posts and Comments API

This project is a REST API built with Spring Boot to manage posts and comments.

## 🚀 Features
- Create, update and delete posts
- Add and manage comments
- Search posts by content
- RESTful endpoints

## 🛠️ Tech Stack
- Java
- Spring Boot
- Maven
- H2 / Database

## 🧠 Purpose
This project was developed as a final assignment to simulate a backend system with real-world behavior.

## 📌 What I learned
- REST API design
- Entity relationships
- Controller, Service and Repository layers
- HTTP methods (GET, POST, PUT, DELETE)

## ▶️ How to run
1. Clone the repository
2. Open in your IDE (Eclipse / IntelliJ)
3. Run the application
4. Access endpoints via Postman or browser
